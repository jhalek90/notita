# notita materials
# Each [section] is one material. Material id 0 is always "air" (built in;
# an [air] section may only set conductivity and heat_capacity).
# Keys:
#   kind            solid | powder | liquid | gas | special (flames)
#   label           name shown in the UI (default: section name)
#   density         kg/m^3-ish; denser things sink through lighter fluids (air = 1.2)
#   viscosity       liquids: 0 runs freely .. 1 barely spreads
#   spread          liquids/gases: max sideways pixels per tick (0..16)
#   slide           powders: chance per tick to slide off a pile (lower = steeper piles)
#   gravity         gravity scale (default 1)
#   max_fall        terminal speed in pixels per tick (1..16, default 12)
#   color           #rrggbb or #rrggbbaa
#   color_variation per-pixel brightness spread (0..128)
# Heat:
#   conductivity    0..1, how fast heat moves through it (pairs use the harmonic mean)
#   heat_capacity   energy per degree per cell (default 1; air 0.25)
#   spawn_temp      temperature of freshly placed cells in C (default 20)
#   mass            whole mass units per cell (default 1; air and flames 0).
#                   Every change below must keep the mass, or it is rejected at load.
# State changes (one going up, one going down; hot point must be above cold point):
#   melt_point / boil_point  + melts_into / boils_into
#   freeze_point / condense_point + freezes_into / condenses_into
#   latent_heat     energy taken by the hot change (given back by the reverse one)
#   change_chance   chance per tick to change once past the point (default 0.35)
# Fire:
#   ignite_point    starts burning at this temperature when touching air
#   burn_time       ticks it burns (1..255); burn_heat = energy released per tick
#   burn_max_temp   burning adds no heat above this (default 900)
#   burns_into      what it becomes when burnt out; burn_residue + residue_chance
#                   for an optional second product (e.g. ash)
#   flame_chance    chance per tick to throw a flame into the air next to it
#   flame           the flame material (default "flame"); flames use life_min/life_max
# Reactions between two materials live in data/reactions.luau.
# Unknown keys are kept for later phases.
