# notita materials
# Each [section] is one material. Material id 0 is always "air" (built in;
# an [air] section may only set conductivity and heat_capacity).
# Keys:
#   kind            solid | powder | liquid | gas | special (flames)
#   label           name shown in the UI (default: section name)
#   density         kg/m^3-ish; denser things sink through lighter fluids (air = 1.2)
#   viscosity       liquids: 0 runs freely .. 1 barely spreads
#   spread          liquids/gases: max sideways pixels per tick (0..16)
#   slide           powders: chance per tick to slide off a pile (lower = steeper piles)
#   gravity         gravity scale (default 1)
#   max_fall        terminal speed in pixels per tick (1..16, default 12)
#   color           #rrggbb or #rrggbbaa
#   color_variation per-pixel brightness spread (0..128)
# Heat:
#   conductivity    0..1, how fast heat moves through it (pairs use the harmonic mean)
#   heat_capacity   energy per degree per cell (default 1; air 0.25)
#   spawn_temp      temperature of freshly placed cells in C (default 20)
#   mass            whole mass units per cell (default 1; air and flames 0).
#                   Every change below must keep the mass, or it is rejected at load.
# State changes (one going up, one going down; hot point must be above cold point):
#   melt_point / boil_point  + melts_into / boils_into
#   freeze_point / condense_point + freezes_into / condenses_into
#   latent_heat     energy taken by the hot change (given back by the reverse one)
#   change_chance   chance per tick to change once past the point (default 0.35)
# Fire:
#   ignite_point    starts burning at this temperature when touching air
#   burn_time       ticks it burns (1..255); burn_heat = energy released per tick
#   burn_max_temp   burning adds no heat above this (default 900)
#   burns_into      what it becomes when burnt out; burn_residue + residue_chance
#                   for an optional second product (e.g. ash)
#   flame_chance    chance per tick to throw a flame into the air next to it
#   flame           the flame material (default "flame"); flames use life_min/life_max
# Reactions between two materials live in data/reactions.luau.
# Phase 4:
#   miscible        liquids: comma-separated liquids this one blends with (symmetric);
#                   they interdiffuse instead of layering by density
#   anchor          solids: holds everything connected to it in place (bedrock)
#   rigid           solids: false keeps the material static even when unsupported (default true)
#   friction, bounce  Box2D surface values of a body made of it (default 0.6, 0.05)
# Phase 5:
#   hardness        how slowly the player digs it (dig chance per tick = 1 / (1 + 2 * hardness));
#                   default: solids density / 1000, powders and liquids 0
# Phase 6 (lighting, all optional):
#   emissive        light it gives off, linear r, g, b (0..4), e.g. "emissive = 1.6, 0.5, 0.1";
#                   hot pixels glow by temperature on top of this, flames default to their colour
#   opacity         how much light one pixel blocks (0..1); default solids/powders 0.6,
#                   liquids 0.15, gases 0.03, air and flames 0
#   noise           per-pixel hue jitter on top of color_variation (0..0.5, default 0)
# Electricity (all optional; see src/sim/Electric.h):
#   electric        electric conductance per pixel (0..1; missing = insulator)
#   electric_role   source | drain | thermopile | lamp | lamp_lit | plate | switch
#   voltage         source: its potential (default 100); thermopile: volts per degree above ambient
#   toggles_into    lamp <-> lamp_lit and switch open <-> closed (same kind and mass)
#   splits_into     electrolysis: "a, b" - two touching cells carrying current become a and b
#                   (mass(a) + mass(b) must be twice this material's mass)
#   split_current   current through a pixel needed to split it (default 0.05)
#   electric_heat   share of the electric power that turns into heat (0..1, default 1)
# Liquid look (#477, all optional; the app's smooth liquid surface pass):
#   look_deep       colour deep down (#rrggbb); the surface uses color, the ramp runs over
#   look_depth      ... this many pixels (default 24)
#   look_clear      how much of the backdrop shows through near the surface (0..1, default 0.3)
#   look_shine      surface line colour + strength (#rrggbbaa)
#   look_foam       foam / spray colour + strength (#rrggbbaa)
#   look_wobble     surface wave height in pixels (default 0.35); look_shimmer: interior
#                   refraction in pixels (0.25); look_glint: moving highlight strength (0.6)
# Textures (#481, all optional; a pixel's look is picked when it is made or placed
# and sticks to it while it moves):
#   palette         colours to pick from, dark to light, each with an optional weight:
#                   "palette = #5c3f28*4, #6a4a2f*4, #2e2016*0.02" (1..16 colours)
#   texture         clumps | speckle | strata | grain | brushed (default clumps; with no
#                   palette the single colour is used and only the brightness is textured)
#   tex_scale       feature size in pixels (6); tex_stretch: how much longer along the
#                   beam / band than across (6); tex_warp: band and vein waviness in px (0)
#   tex_mix         per-pixel randomness of the colour pick (0..1, 0.25); tex_contrast (1.6)
#   tex_shade       brightness from the noise (0..1, 0.6); tex_jitter: per pixel (0..1, 0.35)
#                   (brightness spans +- color_variation)
#   flecks, specks  "chance, colour": single pixels of palette colour (0-based index)
#   pebbles         "chance, radius, colour": small shaded stones
#   pores           chance of a dark pit pixel
#   panels          "width, height, amount": brightness shift per block (cast panels, bricks)
#   veins           "scale, width in px, colour": thin wandering lines (stone)
#   knots, rings    wood: "chance, radius, colour" knots; growth rings per pixel across the grain
# Unknown keys are kept for later phases.
